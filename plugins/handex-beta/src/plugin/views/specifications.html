Frames Mapeados

Especificações Criadas

Selecione um elemento no canvas e toque no botão + no topo para criar uma especificação.

Áreas Marcadas

Marque uma área da tela (selo numerado) e crie as especificações de acessibilidade dentro dela, usando o botão "+" no cabeçalho de cada área.

Toque em Marcar Área no topo para identificar a primeira seção/bloco da tela. As especificações de acessibilidade são criadas dentro de cada área.

Cada especificação já aplica sozinha no canvas (selo + card real da lib), organizada dentro da section "Especificações de Acessibilidade". O resumo consolidado por área fica pronto na aba "♿ Acessibilidade" do Handoff exportado.

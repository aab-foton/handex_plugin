Design System da Interface do hac

Este documento é sobre a linguagem visual da própria interface do plugin hac (src/plugin/views/*.html, src/plugin/styles/) — não deve ser confundido com o DSC da CAIXA, que o plugin referencia como fonte de componentes reais (isso está coberto na Documentação Técnica, seção 6). Aqui o assunto é: como a própria UI do hac é construída e por que ela segue os padrões que segue.

Diferente da versão anterior deste documento (texto/tabela apenas), esta página é uma referência viva: os componentes abaixo não são imagens nem descrições — são o HTML/CSS real do plugin, renderizado dentro desta própria página, ao lado da explicação de quando/como usar. Página autocontida, sem CDN, sem build step, uso interno apenas (docs/design-system.html, repositório privado — nunca publicar via Pages ou qualquer hospedagem externa).

Base técnica confirmada em código: Tailwind CSS com tema customizado em src/plugin/styles/tailwind.config.cjs (só a paleta blue e os tokens light/dark são estendidos — borderRadius, tipografia e demais escalas usam o padrão do Tailwind 3), mais CSS solto em src/plugin/styles/plugin.css (566 linhas) para overrides globais e componentes que o Tailwind puro não cobre (tooltips, FABs, regras de "uniformidade" de card/input). Ambos compilados para src/plugin/styles/tailwind-compiled.css via npm run bundle:css (não editado à mão).

Fonte: src/plugin/styles/plugin.css (overrides/tokens), src/plugin/styles/tailwind.config.cjs (escala blue e tokens light/dark), src/plugin/modules/accessibility.js (A11Y_CATEGORIES), src/plugin/views/home.html/specifications.html (uso real de #0891B2).

Acento primário do hac

Cyan #0891B2 é a cor de ação/identidade própria do hac — usada no botão "Começar" da Home, ícone central person-standing, banners de onboarding, foco de busca e no paginador do wizard de revisão. Diferente do azul institucional CAIXA (abaixo), que segue sendo usado no header/subheader e nos botões de ação dentro dos modais herdados do Handex.

Azul institucional CAIXA

Escala blue inteira (50–950) redefinida no tema Tailwind para ancorar em #005ca9 (blue-500) em vez do azul padrão — classes utilitárias como bg-blue-600 já resolvem para a cor institucional. plugin.css reforça isso via override global: qualquer botão com bg-[#0070af]/bg-blue-600/bg-blue-500 é forçado para exatamente #005ca9 (hover #004782), mesmo que a view use a cor "errada" por engano — comentário explícito no CSS: "Global overrides for buttons matching the Design System". 3. Espaçamento e border radius

Fonte: contagem de classes em src/plugin/views/*.html + src/plugin/modules/*.js + ui.html; valores de radius são o padrão do Tailwind 3 (não customizado em tailwind.config.cjs, que só estende colors).

Border radius

Ocorrências reais: rounded-xl 169×, rounded-lg 76×, rounded-2xl 66×, rounded-full 62×, rounded-md 5×. rounded-2xl é o padrão consistente em botões primários e nos cards de modal; rounded-xl domina em inputs, badges de categoria e cards de item de lista.

rounded-md — 6px
rounded-lg — 8px (botão-padrão sem classe explícita, fallback global)
rounded-xl — 12px (inputs, badges, cards de item)
rounded-2xl — 16px (botões primários, card de modal)
rounded-full — 9999px (avatares/badges circulares, fab-inline)

Cards/containers ganham border-radius: 16px !important automaticamente via seletor global em plugin.css (qualquer [id$="-card"], .bg-white.dark\:bg-dark-surface ou filho direto de .view > section > div) — não precisa ser declarado view a view.

Fonte: src/plugin/views/modals.html linhas 536–551 (seletor "Detecção Automática / Manual" do modal Marcar Área) — <input type="radio"> visualmente oculto (class="sr-only") dentro de um cartão-<label>, estado marcado lido via has-[:checked].

Fonte: showToast(message, variant) e showSnackbar(message, options), src/plugin/modules/core.js linhas 172–251.

Toast (topo/meio): sucesso (check verde) ou erro (borda+ícone vermelho, variant: 'error') — some sozinho em 3s, sem ação. Snackbar (base): cor de destaque cyan (não verde/vermelho — sinaliza instrução, não confirmação/erro), rounded-2xl, botão de fechar (X) sempre presente, botão de ação opcional (actionLabel/onAction), sem timeout automático por padrão (permanece até fechamento manual, a menos que options.duration seja informado). Padrão GOV.BR de snackbar: mensagem + ação/fechamento manual para conteúdo que exige leitura mais atenta.

A cor de acento cyan (#0891B2) permanece igual nos dois temas — o que muda é o tom de fundo/texto ao redor (ex.: dark:text-cyan-400 em vez do hex fixo, para manter contraste sobre fundo escuro). As 5 cores de categoria também não mudam de tom entre os temas — só o fill de fundo ganha opacidade reduzida em vez do hex sólido claro (evidência: uso consistente de bg-{cor}/10 a /20 em dark mode nas views, ex. dark:bg-cyan-900/20 em home.html linha 16).

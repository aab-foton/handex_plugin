# Prompt para NotebookLM — infográfico do HAC

> Fontes: as mesmas do vídeo (BASE-CONHECIMENTO-HAC.md + os prints). Cole o
> texto abaixo da linha no campo de instruções do infográfico.

---

Crie um infográfico vertical, em **português do Brasil**, que explique em uma
única imagem como documentar acessibilidade com o **HAC — Handoff de
Acessibilidade CAIXA**, plugin do Figma. Use apenas o guia e os prints
anexados. O foco é o mobile; o web só aparece onde indicado.

**Público e leitura.** Designers da CAIXA que nunca usaram o HAC. Deve ser
entendido em um minuto: frases de até 12 palavras, sem parágrafos, e um número
ou ícone por bloco.

**Estilo.** Identidade CAIXA: azul #005CA9 dominante, laranja #F39200 só como
destaque, fundo branco ou cinza claro, tipografia sem serifa. Como é um
material de acessibilidade, o próprio infográfico precisa ter alto contraste
(mínimo AA) e nunca depender só da cor para informar algo. Cores dos conectores:
verde-limão #AFCA0B, amarelo #FCBE05 e vermelho #D93636, sempre com o símbolo
dentro do círculo.

**Estrutura, de cima para baixo.**

1. **Título:** "Documente a acessibilidade da tela direto no Figma".
   Subtítulo: "HAC — Handoff de Acessibilidade CAIXA".
2. **Faixa de destaque:** "O design original nunca é alterado. Tudo é
   desenhado numa réplica." Com ícone de duas telas.
3. **Trilha de 5 passos numerados**, ligados por setas:
   - **1 Preparar.** Escolha Super DSC Mobile ou Web. Cole as telas na página
     do handoff. Clique em Selecionar Tela.
   - **2 Tabulação** (etiqueta: Web e Mobile). Shift + clique nos elementos
     interativos, na ordem. Criar ordem de tabulação. Simular leitura para
     ouvir.
   - **3 Swipe** (etiqueta: só Mobile). Shift + clique em todos os elementos
     da tela. Criar trilha de ordem de leitura.
   - **4 Leitor de Tela** (etiqueta: Mobile). + Nova spec. Escolha o conector.
     Aplicar.
   - **5 Fechar.** Gerar Handoff. Finalizar troca "rascunho" por v1.0.
4. **Quadro comparativo "Tabulação × Swipe".**
   - Tabulação: só elementos interativos. Para teclado, mouse programável e
     acionadores. Resultado: selos numerados.
   - Swipe: todos os elementos da tela. Navegação com Basic Swipe, sem os
     atalhos do rotor. Resultado: trilha com setas.
5. **Quadro "Os 3 conectores do Leitor de Tela"**, três cartões com o selo:
   - **1** Elementos e Imagens: interativos e imagens com conteúdo.
   - **H** Títulos: estrutura da página. No mobile todo título usa o mesmo H.
   - **Ø** Elemento Decorativo: não deve ser lido pelo leitor de tela.
6. **Rodapé com duas dicas:** "O label descreve a função, não o tipo do
   componente" e "A spec nasce travada: use o cadeado para ajustar".

**Regras.**
- Não invente funções, botões ou números que não estejam no guia ou nos
  prints.
- Escreva os nomes dos botões exatamente como na interface.
- Prefira ícones e ilustrações simples. Se usar miniaturas dos prints, no
  máximo três: 094949 (trilha de swipe), 095224 (spec criada) e 095714
  (documento final).

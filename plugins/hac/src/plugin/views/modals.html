        Estrutura da Página

        Utilizado para marcar elementos semânticos que estruturam o "esqueleto" de uma página, indicando as seções de conteúdo e para que servem, exemplos: <header>, <main>, <footer>, etc.

        Nível de Título

        Utilizado para estruturar os cabeçalhos da interface (H1-H6) logicamente. O H1 é o título principal (único por página), seguido por H2, H3 e assim por diante. Essa ordem permite que usuários de leitores de tela entendam o sumário do conteúdo.

        Utilizado para estruturar os cabeçalhos da interface, permitindo que o leitor de tela navegue diretamente entre os tópicos que foram definidos como títulos de conteúdo.

        Elementos Interativos e Imagens

        Utilizado para referenciar componentes no DSC Super App, garantir nome acessível aos elementos e descrever textos alternativos nas imagens.

        Elementos Decorativos

        Utilizado para marcar os elementos que devem ser ignorados pelo leitor de tela, como por exemplo imagens que não passam conteúdo ou função, formas abstratas, divisores ou ícones decorativos.

        Informações adicionais

        Caso queira contemplar algum elemento/componente que não se encaixa nas outras categorias, use esta pra descrever o item e apontar suas observações: é a única categoria com formato livre.

        Toda categoria segue os mesmos campos: Descrição (como o elemento deve ou não ser lido) e Notas de Código (apontamento técnico pro dev), quando aplicável à variante escolhida.

        Selecionar Tela (selo azul numerado) é o pré-requisito: identifica uma seção ou bloco da tela e agrupa, na listagem lateral, todas as especificações criadas dentro dela. Cada uma das 5 categorias acima é uma Especificação, sempre criada dentro de uma tela já selecionada.

        Contorno (padrão) envolve o elemento inteiro com uma moldura, com o selo embutido num dos cantos. Linha liga um ponto do elemento ao card de detalhamento com um traço, sem contornar a tela, útil quando o elemento é pequeno ou está muito próximo de outros. Os dois são desenhados sobre uma cópia de trabalho do elemento, nunca sobre o frame original do seu design: o original nunca é alterado.

        Um ícone ao lado de um texto que já explica a mesma coisa (ex.: ícone de lixeira ao lado do texto "Excluir") é decorativo: o texto já basta. Já um ícone sozinho, sem texto ao lado, que representa uma ação (ex.: só o ícone de lixeira, sem rótulo visível) é Elemento e Imagem, e precisa de descrição explicando a função.

        Uma imagem que só ilustra/decora a tela (banner, ilustração de fundo) é decorativa. Uma imagem que carrega informação que não está em texto em nenhum outro lugar (gráfico, print de comprovante, foto de um documento) é Elemento e Imagem e precisa de texto alternativo descrevendo o conteúdo.

        No final, o time de dev não recebe um documento à parte: consome direto o Handoff de Acessibilidade gerado na aba Handoff de cada tela, que reúne Descrição e Notas de Código de cada especificação já registrada no canvas.

        Sobre o hac

        HAC — Handoff de Acessibilidade CAIXA. Documenta, direto no canvas do Figma, como cada elemento da tela deve ser interpretado por um leitor de tela e em que ordem o teclado deve navegá-la.

Fluxos de Tela

Como funciona

A seta desenhada no canvas segue a ordem de seleção: do primeiro elemento clicado para o segundo.

Use o ícone de olho no card para ocultar/exibir a conexão sem excluí-la.

Use o ícone de lixeira para remover a conexão do canvas e da lista.

Selecione dois elementos no Figma e use o botão + Conectar Frames para mapear fluxos de navegação.

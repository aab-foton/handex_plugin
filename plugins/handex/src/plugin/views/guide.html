Como usar o plugin

Registra o contexto do que está sendo entregue — título, objetivo, equipe responsável e, dentro de Contexto de Negócio, o briefing estratégico, as regras de negócio/HUs e os links de referência. Esse contexto aparece no topo da ficha final, para o dev entender o "porquê" da entrega antes de mergulhar no "como" — sem precisar te perguntar no Slack ou adivinhar pelo protótipo.

Não é uma leitura automática que basta rodar uma vez: o scan traz cores, tipografia, componentes e vetores do frame, já com um batimento automático contra o Design System CAIXA — mas o critério é exigente. Sem token vinculado, o item conta como fora do padrão, sem meio-termo. Cabe a você revisar cada caso, como no Check Designs nativo do Figma, e decidir: ajustar o elemento ou justificar o desvio por escrito. Quando o frame traz um componente inédito, ainda fora do DSC, a ferramenta registra as propriedades dele como referência para uma futura incorporação.

Exportar

  1. →O botão Baixar, no rodapé da home, exporta o JSON completo a qualquer momento, sem precisar sair da tela em que você está.
  2. →Para exportar em Markdown ou o Briefing em separado, acesse Gerar Ficha de Handoff → use os botões de exportação na tela de resumo.
  3. →O JSON é a fonte completa de dados — contém specs, medidas, fluxos, propriedades e tokens escaneados. Ideal para integrações com outros sistemas.

Importar

  1. →Clique em Importar JSON na home e selecione um arquivo exportado anteriormente. O plugin restaura todos os dados e incrementa a versão automaticamente.
  2. →Após importar, escolha o que recriar no canvas: Ficha Técnica, Cards de Spec, Medidas e/ou Fluxos.
  3. →Fluxos só são recriáveis se o backup foi gerado nesta versão do plugin ou mais recente — backups mais antigos não salvavam o vínculo com os elementos conectados, e o fluxo aparece como não recriável.

Antes de apagar

  1. →O botão Baixar, no rodapé da home, exporta um backup completo em JSON a qualquer momento — recomendado antes de qualquer uma das ações abaixo, já que nenhuma delas pode ser desfeita. O mesmo botão também aparece no topo do modal de limpeza, como lembrete.

Apagar dados do plugin

  1. →Reseta o progresso salvo no Handex (frames registrados, specs, medidas e fluxos do hub). Não remove nada do canvas — só o que o plugin está rastreando internamente.

Apagar conteúdo do canvas

  1. →Remove de verdade os elementos que o Handex criou no canvas desta página — marque só o que quer apagar: Ficha de Handoff, Specs, Medidas e/ou Fluxos (ou "Selecionar tudo").
  2. →Se apagou algo por engano, um backup em JSON baixado antes permite trazer de volta via Importar JSON.

Algumas layers geradas pelo plugin são bloqueadas

Medidas e Fluxos são criados com bloqueio de edição para preservar a integridade do handoff. Specs nascem destravadas e podem ser bloqueadas manualmente pelo ícone de cadeado; a Ficha de Projeto também nasce destravada. Para remover qualquer item, use os botões de exclusão dentro do próprio plugin (ou "Apagar conteúdo do canvas", no ícone de lixeira da home).
